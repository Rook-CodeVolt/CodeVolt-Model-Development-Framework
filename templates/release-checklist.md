# Model release checklist

- [ ] Candidate passed predetermined capability, regression, and safety gates.
- [ ] Evidence bundle is complete, immutable, and independently verified.
- [ ] Dataset cards pass licence, privacy, consent, and contamination review.
- [ ] Model card states intended use, prohibited use, limitations, and risks.
- [ ] Artifact hashes, dependencies, and reproducible environment are recorded.
- [ ] Security review covers model files, adapters, serving path, and supply chain.
- [ ] Named owner accepted monitoring and incident responsibilities.
- [ ] Rollback was tested against the target environment.
- [ ] Promotion received the approvals required by governance.
- [ ] Release notes include material changes and known negative results.
