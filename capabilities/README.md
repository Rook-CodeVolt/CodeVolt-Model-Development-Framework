# Capability registry

Each capability begins as a proposal and advances only with evidence. Add one Markdown file containing:

- purpose and user need;
- lifecycle status;
- upstream project, pinned version, and licence;
- threat and privacy considerations;
- adapter contract;
- tests and reproducible experiment;
- evidence location;
- accept, defer, or reject decision.

Initial candidates include trainer adapters for TRL/PEFT, Unsloth, MiniMind, Axolotl, and LLaMA-Factory; evaluation adapters for lm-evaluation-harness and other independent suites; and deployment evidence from llama.cpp or vLLM. Listing a candidate is not endorsement or bundled support.
