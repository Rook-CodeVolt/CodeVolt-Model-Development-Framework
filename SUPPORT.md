# Support

This is an early open-source project maintained on a best-effort basis.

- Use GitHub Discussions for questions, design conversations, and sharing experiments.
- Use the issue forms for reproducible bugs and capability proposals.
- Use private vulnerability reporting for security or sensitive-data concerns.

Before opening an issue, search existing issues and include the framework version, operating system, Python version, manifest with sensitive content removed, expected result, actual result, and the smallest reproduction you can provide.

See [`docs/FEEDBACK.md`](docs/FEEDBACK.md) for full guidance on choosing a channel, submitting safe evidence, how autonomous agents should report findings, and how accepted feedback is triaged and closed. This project does not commit to a response-time SLA.
