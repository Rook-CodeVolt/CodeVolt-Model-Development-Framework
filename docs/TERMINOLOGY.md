# Terminology

- **Adapter:** a narrow integration implementing a CodeVolt contract for an external or internal engine.
- **Artifact:** output produced by training, such as model weights or an adapter checkpoint.
- **Assurance gate:** policy that converts complete evaluation evidence into an accepted or rejected decision.
- **Baseline:** immutable reference against which a candidate is evaluated.
- **Candidate:** artifact proposed as an improvement.
- **Evidence bundle:** manifest, provenance, measurements, and decision for a run.
- **Experiment:** bounded attempt to test a declared hypothesis.
- **Invalid:** a run that cannot be judged because required evidence is missing, corrupt, or unverifiable.
- **Learning event:** structured record of a failure, correction, or useful success.
- **Promotion:** separately authorised act of making a candidate available for a target use.
- **Proposal:** reviewable hypothesis for addressing one or more learning events.
